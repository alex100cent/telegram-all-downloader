# Совместимость и доказательства

Дата: 9 октября 2026. Версия расширения: 0.1.0.

Автоматическая проверка: TypeScript и ESLint без ошибок, **106 unit/integration-тестов и 8 E2E-сценариев пройдены**. Собранное MV3-расширение проверено в Chromium 156.0.8078.4: два адаптера, точный SHA-256, очередь, отмена, восстановление фонового процесса, поздний meta CSP без unsafe-eval и сохранение подключения после `history.pushState`/изменения `location.hash`. В двух последних сценариях после навигации внутри Web A успешно сохраняется синтетический файл. E2E использует собственные страницы Telegram и настоящий OPFS writer; нативный picker заменён тестовой функцией. Подробнее: [E2E](../tests/e2e/README.md).

Смена чата внутри SPA через hash/pushState сохраняет исходный документ и сессию расширения. Настоящая перезагрузка или замена документа, уход с поддерживаемого Telegram Web и закрытие вкладки прерывают зависимый от страницы путь. Одного события `chrome.tabs.onUpdated` со статусом `loading` недостаточно для признания сессии утраченной.

Проверка чистого исполнителя на синтетическом потоке 1 GiB подтверждает ограничение размера порций; она не является сетевой проверкой Telegram, измерением общего расхода памяти Telegram или проверкой записи 1 GiB на диск.

Живые скачивания реальных образцов из Telegram пока не подтверждены. До заполнения живой матрицы нельзя считать обязательные критерии MVP из PLAN.md полностью пройденными. Для каждого живого результата записать браузер/build, A/K, тип файла, доступ публичный/приватный/protected, размер, ожидаемый и фактический хеш, поведение отмены и расход памяти. Идентификаторы частных чатов и содержимое файлов в этот документ не помещать.
