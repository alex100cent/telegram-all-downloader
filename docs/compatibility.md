# Совместимость и доказательства

Дата: 9 октября 2026. Версия расширения: 0.1.0.

Автоматическая проверка: TypeScript и ESLint без ошибок, 104 unit/integration-теста. Собранное MV3-расширение проверяется шестью E2E-сценариями в Chromium 156.0.8078.4: два адаптера, точный SHA-256, очередь, отмена, восстановление фонового процесса и поздний meta CSP без unsafe-eval. E2E использует синтетические страницы Telegram и настоящий OPFS writer; нативный picker заменён тестовой функцией. Подробнее: [E2E](../tests/e2e/README.md).

| Среда            | Исследование протокола                 | Автоматические fixtures                                   | Живые загрузки                       |
| ---------------- | -------------------------------------- | --------------------------------------------------------- | ------------------------------------ |
| Web A / Chromium | Официальный source + production bundle | Worker RPC, identity, форматы, отмена, диапазоны          | Ожидают проверки                     |
| Web K / Chromium | Официальный source + production bundle | Runtime RPC, identity, форматы, отмена, диапазоны         | Ожидают проверки                     |
| Chrome macOS     | Установлен 155.0.8059.40               | Отдельный тестовый профиль                                | Ожидают проверки                     |
| Яндекс macOS     | Не установлен в среде разработки       | Общие Chromium-контракты; это не проверка Яндекс.Браузера | Пользователь проверит самостоятельно |

Проверка чистого исполнителя на синтетическом потоке 1 GiB подтверждает ограничение размера порций; она не является сетевой проверкой Telegram, измерением общего расхода памяти Telegram или проверкой записи 1 GiB на диск.

До заполнения живой матрицы нельзя считать обязательные критерии MVP из PLAN.md полностью пройденными. Для каждого живого результата записать браузер/build, A/K, тип файла, доступ публичный/приватный/protected, размер, ожидаемый и фактический хеш, поведение отмены и расход памяти. Идентификаторы частных чатов и содержимое файлов в этот документ не помещать.
