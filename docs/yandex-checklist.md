# Проверка в Яндекс.Браузере на macOS

Пока строки ниже не заполнены живыми результатами, поддержка Яндекс.Браузера считается **непроверенной**. Успешные проверки в Chrome и Chromium-fixtures не переносятся на Яндекс автоматически.

## Подготовка

1. Соберите расширение: `npm ci && npm run build` (или распакуйте ZIP из CI / `npm run zip`). Нужна папка `.output/chrome-mv3`.
2. Откройте страницу расширений (`browser://extensions`), включите режим разработчика и загрузите распакованную папку `.output/chrome-mv3`. Если путь в меню отличается, запишите фактические шаги.
3. Запишите версию браузера (`browser://version`, первая строка) и версию macOS.
4. Запишите сборку расширения: popup → Настройки → «О сборке». То же значение видно в версии расширения на странице расширений: `0.1.0 (<сборка>)`. Сборка вида `<коммит>-modified.<хеш>` содержит изменения вне коммита — так и укажите в отчёте.
5. Перезагрузите уже открытые вкладки `web.telegram.org/a/` и `/k/`. Отключите другие загрузчики Telegram на время проверки.
6. Подготовьте образцы: `node scripts/qa-samples.ts generate ~/tad-samples --media --large=100m`. Отправьте их **файлом** в тестовый канал или используйте уже загруженные владельцем образцы. Подробности — в [плане ручной проверки](manual-testing.md).

## Сценарии

Каждый сценарий выполнить в Web A и Web K. Для проверки системного диалога вкладка Telegram должна быть активной.

| ID  | Сценарий                | Что сделать                                                                                   | Ожидаемый результат                                                                                |
| --- | ----------------------- | --------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| Y1  | Установка и подключение | Открыть popup при открытом Telegram                                                           | «Подключено» и метка Web A или Web K                                                               |
| Y2  | Системный диалог        | Нажать ↓ у вложения, выбрать место, сохранить                                                 | Диалог Яндекса/macOS открывается сразу; popup показывает «Сохранено»                               |
| Y3  | Основные форматы        | Сохранить аудио (MP3), фото, видео, голосовое и PDF                                           | Размер и SHA-256 совпадают с образцом или с тем же файлом из Chrome; `verify` без FAIL             |
| Y4  | Большой файл            | Сохранить `tad-large-100m.bin` (104 869 945 байт)                                             | Точный размер и SHA-256 из `manifest.json`                                                         |
| Y5  | Отмена                  | Во время Y4 нажать кнопку загрузки ещё раз или «Отменить» в popup                             | «Отменено»; файл не отмечен сохранённым. Записать размер оставшегося файла (пустой файл допустим)  |
| Y6  | Закрытие popup          | Начать Y4, закрыть popup, дождаться конца                                                     | Загрузка продолжается; при повторном открытии — «Сохранено»                                        |
| Y7  | Закрытие и перезагрузка | Во время Y4 закрыть вкладку Telegram; повторить с перезагрузкой                               | «Прервано», код `interrupted`; нет «Сохранено»                                                     |
| Y8  | Повтор                  | Для прерванной или отменённой загрузки нажать «Повторить в Telegram», затем «Сохранить снова» | Открывается исходная вкладка; новая загрузка требует нового выбора файла и завершается «Сохранено» |

## Формат отчёта

Скопируйте блок для каждого результата. Не указывайте названия чатов, ссылки, имена личных файлов и не прикладывайте скриншоты с личным содержимым.

```text
Дата:
macOS:
Яндекс.Браузер (browser://version):
Сборка расширения (Настройки → О сборке):
Клиент: Web A / Web K
Сценарий: Y1–Y8
Образец: категория и размер (например, PDF 608 байт, tad-large-100m)
Результат: ожидаемый / отличается — как именно
SHA-256 совпал: да / нет / не применимо
Код ошибки и диагностика (popup → «Диагностика»), если была ошибка:
```

Результаты переносятся в [матрицу совместимости](compatibility.md) с отметкой «Яндекс». Сбой, характерный только для Яндекса, исправляется отдельно; непроверенные сценарии остаются в статусе «ожидает».
