# Проверка на настоящем Telegram

Использовать собственные тестовые вложения и известные эталоны. Сначала установить распакованное расширение, перезагрузить Telegram и отключить другие расширения-загрузчики на время сравнения. Для Яндекс.Браузера есть отдельный [короткий чек-лист](yandex-checklist.md).

## Сборка

Перед каждой серией записать сборку: popup/менеджер → Настройки → «О сборке», либо версию на странице расширений — `0.2.0 (<сборка>)`.

- `35536af` — сборка из коммита без локальных изменений.
- `35536af-modified.1a2b3c4d` — к коммиту добавлены изменения; хеш различает разные наборы изменений. Такую сборку нельзя выдавать за чистый коммит.
- `unversioned` — при сборке не было данных Git.

Сборку CI отличает пометка «Сборка CI #N» в том же блоке. `npm run build` и `npm run zip` пересобирают `.output/chrome-mv3`: завершите сборку до перезагрузки расширения и не пересобирайте его во время живой проверки.

## Для каждого Web A/K и браузера

1. Фото, видео, MP3/подкаст, voice, кружочек, MP4-анимация, PDF, неизвестный файл, WebP/TGS/WebM-стикер: сохранить, сравнить формат и байты с доступным в Telegram эталоном.
2. Проверить публичный, приватный и отдельный protected-канал. Private не означает protected.
3. Непроигранный файл, частично проигранный, два аудио с одинаковыми именами/длительностью, соседний prefetch: сохранить именно выбранный документ, не изменить текущий плеер.
4. Отдельный элемент альбома и просмотрщик. Если просмотрщик не даёт точной связи, проверить доступную кнопку в сообщении и записать ограничение.
5. Два быстрых клика, разные вкладки с тем же файлом, разные чаты/аккаунты: один активный writer, правильная дедупликация и identity.
6. Отмена во время чтения, отказ в picker, ошибка диска, offline, reload/закрытие вкладки, остановка extension worker: без ложного успеха и скрытого дублирования.
7. Файлы 100 MiB, 1 GiB и около 2 GiB; около 4 GiB при наличии. Записать peak memory всего пути, фактический размер и хеш. Проверить свободное место до больших тестов.
8. Popup light/dark, RU/EN, клавиатура, очистка/отключение истории. История удаляется, скачанный файл остаётся.
9. Оставить системный диалог сохранения открытым на минуту: после подтверждения должен сохраниться тот же файл, даже если Telegram очистил локальный индекс сообщений. Проверить отмену во время повторного запроса метаданных.
10. После перерисовки сообщения кнопка возвращается; во время активной загрузки новая кнопка управляет прежним заданием и не создаёт второй writer.

После отключения/включения или обновления расширения перезагрузить Telegram: Web A требуется hook до создания API worker.

Для проверки нативного picker вкладка Telegram должна быть активна. Переключение на другую вкладку до открытия диалога может отменить его; это не проверка передачи файла.

## Группы и папки: ручная проверка 0.2.0

Сценарии ниже пока требуют проверки владельцем в настоящих Web A и K через системный выбор папки. Синтетические E2E с OPFS не подтверждают нативный диалог или работу с реальными вложениями. Используйте отдельную тестовую папку и собственные файлы; её содержимое понадобится для проверки совпадений имён.

1. **Выбор и обновление.** Открыть «Скачать несколько» из Telegram и через popup/менеджер. При нескольких подключённых вкладках выбрать нужную. Проверить типы, отдельные элементы и кнопку выбора показанных элементов альбома. Прокрутить чат вручную, обновить список; не принимать список до 200 вложений за весь канал. Убедиться, что фильтр типа в панели сохраняет уже выбранные скрытые файлы и правильно считает итог.
2. **Одна папка, точные файлы.** Выбрать несколько разных вложений, оставить исходные имена и «Сохранить оба». Одним действием выбрать папку. Проверить последовательную запись, реальные размеры и SHA-256 каждого файла. Закрыть панель, popup и менеджер во время передачи: очередь продолжается, пока открыт Telegram.
3. **Совпадающие имена.** Подготовить существующий файл и два выбранных вложения с одинаковым именем. «Сохранить оба» создаёт разные имена и сохраняет исходный файл. «Пропустить» не меняет существующий файл, даёт статус «Пропущено» и не выдаёт его за сохранённый.
4. **Перезапись и имена.** Только на тестовых файлах явно выбрать «Перезаписать»: успешная запись заменяет содержимое. Отдельно проверить ошибку/отмену до финализации — прежние байты сохраняются, ложного успеха нет. Проверить шаблоны ID/номер + имя, Unicode и длинные имена; фактическое имя в менеджере совпадает с диском.
5. **Менеджер.** Поиск по имени, фильтры типа/статуса/группы, страницы 25/50/100, выбор нескольких страниц до 200 записей. Изменение фильтра снимает выбор. Массовая отмена отменяет только выбранные ожидающие/скачиваемые файлы; финализация не предлагает отмену. RU/EN, обе темы, Tab/Space/Escape, в том числе два одинаковых имени в панели.
6. **Повтор.** Получить ошибку и отмену, выбрать их в менеджере, нажать повтор. Проверить, что новая передача требует нового клика и выбора папки в Telegram. Успешные и пропущенные записи не повторяются массовой кнопкой. Сравнить accepted/rejected с фактически открытыми выборами и результатом новой очереди.
7. **Потеря вкладки и диалога.** Перезагрузить/закрыть исходный Telegram во время группы: зависимые задания прерваны, файлы не помечены сохранёнными. Индивидуальный повтор открывает исходное сообщение, если есть ссылка. Для отклонённого массового повтора восстановить источник вручную. Отменить системный диалог папки: новых заданий нет; следующее нажатие работает.
8. **История и сводки.** Сравнить счётчики выбранной группы с её сохранёнными записями, включая «Пропущено». Очистить или отключить историю: завершённые записи исчезают, сводки меняются, активная очередь и файлы на диске остаются. После перезагрузки для повтора снова нужен выбор назначения — папка автоматически не восстанавливается.

## Образцы и сверка

Синтетические образцы не содержат личных данных и воспроизводимы. Генератор записывает их и `manifest.json` с размерами и SHA-256:

```sh
node scripts/qa-samples.ts generate ~/tad-samples --media
node scripts/qa-samples.ts generate ~/tad-samples-large --large=100m,1g,2g
```

- Без флагов: PDF, ZIP, TXT, файл без расширения, неизвестный тип `.tadqa` и файл с Unicode-именем.
- `--media` (нужен FFmpeg): FLAC, M4A, GIF, MP4-анимация, WebM. `--long-video` добавляет MP4 длиной 11 минут (больше 100 MiB).
- `--large`: `100m`, `1g`, `2g`, `4g`. Размеры не кратны 512 KiB, поэтому последняя порция неполная. `2g` меньше предела Telegram 2000 MiB; `4g` требует Telegram Premium (предел 4000 MiB).

Документы и медиа, отправленные **файлом без сжатия**, должны совпасть с образцом побайтно. Фото, GIF и видео, отправленные как медиа, Telegram может преобразовать: GIF становится MP4-анимацией. Для них сравнивать копии из A и K между собой и проверять формат, а не исходник до загрузки. TGS и WebM-стикеры отправить из любого публичного набора стикеров.

Проверка скачанных файлов (папки или отдельные файлы):

```sh
node scripts/qa-samples.ts verify ~/tad-samples/manifest.json ~/Downloads/tad-a ~/Downloads/tad-k --decode
```

Команда печатает размер, SHA-256, распознанный формат и результат: `PASS`, `FAIL` или `INCONCLUSIVE`. Известный образец должен совпасть одновременно по размеру и хешу: даже файл другого размера получает `FAIL`, а не пропускается. Дополнительно проверяются TGS (gzip + Lottie с `tgs=1`), полное декодирование FFmpeg с `--decode` и группы одинаковых копий A/K.

Коды выхода:

- `0` — все выбранные файлы совпали с известными эталонами по размеру и SHA-256; запрошенные дополнительные проверки также завершились успешно.
- `1` — найдено несовпадение с известным эталоном или ошибка проверки формата/декодирования.
- `2` — результат не доказан: неизвестный файл без точного совпадения с манифестом, пустой набор файлов, недоступная дополнительная проверка или неверные параметры.

Для переименованного файла явно укажите **имя образца из манифеста** через `--expected=<имя-образца>`. Этот эталон применяется **ко всем входным файлам данного запуска**; не передавайте вместе копии разных исходных образцов. Пример для двух переименованных копий одного образца:

```sh
node scripts/qa-samples.ts verify ~/tad-samples/manifest.json ~/Downloads/copy-a.pdf ~/Downloads/copy-k.pdf --expected=tad-sample-document.pdf
```

`tad-sample-document.pdf` — PDF из генератора; для другого образца укажите точное значение `file` из своего `manifest.json`. Без явного эталона переименованный файл может быть распознан по полному совпадению размера и SHA-256; несовпавший файл с неизвестным именем остаётся `INCONCLUSIVE`. Совпавшие копии A/K сами по себе не доказывают полноту: обе могут быть одинаково усечены. Для преобразованных Telegram медиа нужен эталон доступного в Telegram результата, а не исходник до преобразования.

На macOS отдельный файл можно сверить так: `shasum -a 256 /path/to/file`. В отчёт добавлять результат сравнения, но не приватное содержимое, названия каналов или ссылки.

## Большие файлы и память

1. Проверить свободное место: для `2g` нужно около 4,2 ГБ (образец и скачанная копия).
2. Открыть диспетчер задач браузера (Chrome: Shift+Esc). Найти процессы вкладки Telegram, а для Web K также `Shared Worker` и `Service Worker` `web.telegram.org`: через них проходят байты. Записать их ID процессов.
3. До нажатия ↓ запустить замер и остановить его Ctrl+C после «Сохранено»:

   ```sh
   node scripts/qa-samples.ts memory 1234,5678
   ```

   Команда суммирует RSS указанных процессов раз в 0,5 с и печатает базовое значение, пик и прирост. Прирост не должен расти пропорционально размеру файла. Для сверки записать также «Объём памяти» из диспетчера задач на пике.

4. Во время передачи прокрутить чат и открыть popup: интерфейс должен отвечать. Отдельно отменить загрузку на середине и убедиться, что прирост памяти исчезает, а popup показывает фактический результат.
5. Записать: размер, SHA-256 (совпал/нет), длительность, пик и прирост памяти, A/K, браузер, сборку.

Наибольший проверенный размер, предел исполнителя 4 GiB и отдельный путь фото Web A (32 MiB) указываются в отчёте раздельно.

## Отчёт об ошибке

При неудачной загрузке popup показывает понятную причину и стабильный код (`Код: disk_error`). Кнопка «Диагностика» открывает текст, который будет скопирован: версия и сборка, браузер и ОС, клиент, тип/MIME, округлённый размер, состояние, код и процент передачи. Имён файлов, ссылок и идентификаторов в нём нет. Этот текст можно приложить к [issue](https://github.com/alex100cent/telegram-all-downloader/issues/new).
