# Telegram All Downloader

Расширение для скачивания отдельных вложений из Telegram Web A и K. Бесплатное, с открытым кодом и локальной очередью. Стек: WXT, TypeScript, React, Manifest V3.

**Статус 0.1.0 — предварительная версия:** в Chrome 155 на macOS через Web A и Web K проверены шесть типов реальных вложений из приватного канала с защитой содержимого: MP3, JPEG, MP4-видео, голосовое Ogg/Opus, кружок MP4 и статический WebP-стикер. Файлы сохранены через системный диалог; размеры и SHA-256 образцов из A/K совпали. Наибольший сохранённый образец — **29 109 155 байт (около 27,8 MiB)**. Подробности и границы проверки — в [матрице совместимости](docs/compatibility.md).

PDF/ZIP, GIF/анимации, TGS/WebM-стикеры и файл размером 1 GiB ещё требуют живой проверки. Поддержка всех форматов и больших файлов пока не подтверждена. Яндекс.Браузер владелец проверит отдельно.

## Что реализовано

- Фото, видео, музыка/подкасты, voice, кружочки, анимации, документы и стикеры.
- Кнопка около вложения, точная привязка к сообщению и аккаунту, без запуска аудиоплеера.
- Последовательная очередь, прогресс, отмена, история и повтор через исходную вкладку.
- Потоковая запись документов порциями до 512 KiB; фото — отдельным ограниченным путём.
- RU/EN, светлая/тёмная тема, настройки истории.
- Работа через текущую сессию Telegram, без отдельного входа и сервера медиа.

Массовое скачивание, Stories, аватары и конвертация запланированы отдельно. [План развития](PLAN.md).

## Сборка и установка на macOS

Нужен Node.js 22.18+ и npm.

```sh
npm ci
npm run build
```

1. В Chrome откройте `chrome://extensions`; в Яндекс.Браузере — страницу расширений.
2. Включите режим разработчика, выберите «Загрузить распакованное расширение».
3. Выберите папку `.output/chrome-mv3` внутри проекта.
4. Откройте `https://web.telegram.org/a/` или `https://web.telegram.org/k/` и **перезагрузите уже открытую вкладку**.
5. Откройте сообщение, дождитесь подготовки кнопки ↓, нажмите её и выберите имя/место сохранения в системном диалоге.

`npm run zip` создаёт установочный ZIP в `.output/`. Распакуйте его перед загрузкой в браузер. Подпись и публикация в магазине в эту сборку не входят.

## Как пользоваться

Каждое нажатие выбирает один файл. В альбоме скачивается выбранный элемент. Пока один файл загружается, следующие выбранные файлы ждут в очереди. Для каждой загрузки используется системный выбор файла; замена существующего файла требует подтверждения браузера.

Нажмите кнопку активной загрузки ещё раз или «Отменить» в popup, чтобы остановить её. Повтор после ошибки открывает исходную вкладку и требует нового нажатия «Сохранить снова» для выбора места на диске.

На коротком завершающем этапе «Записывается на диск» отмена уже недоступна: браузер подтверждает сохранение файла.

Закрытие popup не мешает работе. **Telegram-вкладка должна оставаться открытой.** Её закрытие или перезагрузка прерывает зависимые загрузки. История сохраняется, но побайтовая докачка после перезапуска пока не реализована. Выберите файл заново, чтобы повторить загрузку.

Файлы сохраняются в реальном формате: voice может быть OGG, а «GIF» — MP4. Расширение не перекодирует содержимое. Для фотографий сохраняется лучший доступный в Telegram вариант, который может отличаться от файла до сжатия Telegram.

## Ограничения

- Требуется доступ текущего пользователя к сообщению. Расширение не открывает недоступные каналы и неоплаченные вложения.
- Одноразовые и самоуничтожающиеся вложения пока не поддерживаются.
- Исполнитель ограничен 4 GiB на файл; текущий **проверенный в Telegram** размер смотрите в матрице. Потоковый synthetic-тест не доказывает возможность скачать такой размер из Telegram.
- Для Web A фото ограничены 32 MiB; документы сохраняются порциями. Это разные пути загрузки.
- Изменения Telegram могут потребовать обновления адаптера. При неоднозначном источнике расширение откажется от загрузки вместо сохранения другого файла.
- В просмотрщике кнопка доступна только при доказанной связи с сообщением. Если её нет, используйте кнопку в исходном сообщении.
- Firefox, Safari, мобильные браузеры и Windows пока не входят в проверенную поддержку.

## Разработка и проверки

```sh
npm run dev
npm run typecheck
npm run lint
npm test
npm run build
npm run test:e2e
```

E2E использует отдельный тестовый Chromium и синтетические страницы; пользовательский профиль и Telegram-сессия в CI не используются. Для установки тестового браузера: `npx playwright install chromium`.

См. [архитектуру Web A](docs/architecture/web-a.md), [Web K](docs/architecture/web-k.md), [передачу и сохранение](docs/architecture/transport.md) и [план ручной проверки](docs/manual-testing.md).

## Данные и поддержка

Разрешения: локальное хранилище расширения и доступ только к `web.telegram.org`. File System Access запрашивает доступ к выбранному пользователем файлу. Нет аналитики, сервера загрузок и копирования ключей авторизации. Подробнее: [Privacy](PRIVACY.md).

История хранится локально: до 500 завершённых записей, до 30 дней. Её отключение удаляет завершённые записи; скачанные файлы не удаляются. Ошибки можно сообщить через [GitHub Issues](https://github.com/alex100cent/telegram-all-downloader/issues), не прикладывая приватные ссылки, переписки и коды входа.

Донаты необязательны. Ссылка задаётся владельцем в `src/config.ts`; пока она не задана, кнопка скрыта.
