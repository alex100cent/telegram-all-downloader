# Telegram All Downloader

Расширение для скачивания вложений из Telegram Web A и K: по одному или выбранной группой в папку. Бесплатное, с открытым кодом, локальной очередью и отдельным менеджером загрузок. Стек: WXT, TypeScript, React, Manifest V3.

**Статус 0.2.0 — предварительная версия:** добавлены групповой выбор, сохранение в папку и менеджер. Новый сценарий с нативным выбором папки ещё требует живой проверки владельцем; проверки на синтетических страницах не заменяют её. Изменения: [CHANGELOG](CHANGELOG.md).

В версии 0.1.0 в Chrome 155 на macOS через Web A и Web K проверены шесть типов реальных вложений из приватного канала с защитой содержимого: MP3, JPEG, MP4-видео, голосовое Ogg/Opus, кружок MP4 и статический WebP-стикер. Файлы сохранены через системный диалог; размеры и SHA-256 образцов из A/K совпали. Наибольший сохранённый образец — **29 109 155 байт (около 27,8 MiB)**. Это свидетельство для прежнего одиночного сценария. Подробности и границы проверки — в [матрице совместимости](docs/compatibility.md).

PDF/ZIP, GIF/анимации, TGS/WebM-стикеры и файл размером 1 GiB ещё требуют живой проверки. Поддержка всех форматов и больших файлов пока не подтверждена; [список ожидающих проверок](docs/compatibility.md#ожидают-живой-проверки) ведётся в матрице. Яндекс.Браузер владелец проверит отдельно по [чек-листу](docs/yandex-checklist.md).

## Что реализовано

- Фото, видео, музыка/подкасты, voice, кружочки, анимации, документы и стикеры.
- Кнопка около вложения, точная привязка к сообщению и аккаунту, без запуска аудиоплеера.
- Последовательная очередь, прогресс, отмена, история и повтор через исходную вкладку.
- Выбор до 200 обнаруженных вложений, фильтр типа и выбор доступных элементов альбома; одна папка для выбранной группы.
- Политики совпадения имён: сохранить оба, пропустить существующий файл или явно выбрать перезапись.
- Отдельный менеджер: поиск по имени, фильтры типа/статуса/группы, сводки, страницы и массовая отмена/повтор.
- Потоковая запись документов порциями до 512 KiB; фото — отдельным ограниченным путём.
- RU/EN, светлая/тёмная тема, настройки истории.
- Работа через текущую сессию Telegram, без отдельного входа и сервера медиа.

Автоматическая выгрузка всей истории канала, Stories, аватары и конвертация остаются в [плане развития](PLAN.md).

## Сборка и установка на macOS

Нужен Node.js 22.18+ и npm.

```sh
npm ci
npm run build
```

1. В Chrome откройте `chrome://extensions`; в Яндекс.Браузере — страницу расширений.
2. Включите режим разработчика, выберите «Загрузить распакованное расширение».
3. Выберите папку `.output/chrome-mv3` внутри проекта.
4. Откройте `https://web.telegram.org/a/` или `https://web.telegram.org/k/` и **перезагрузите уже открытую вкладку**.
5. Откройте сообщение, дождитесь подготовки кнопки ↓, нажмите её и выберите имя/место сохранения в системном диалоге.

`npm run zip` создаёт установочный ZIP в `.output/`. Распакуйте его перед загрузкой в браузер. Подпись и публикация в магазине в эту сборку не входят.

## Как пользоваться

Для одного файла нажмите кнопку у вложения. В альбоме скачивается выбранный элемент. Место и имя выбираются через системный диалог; замена существующего файла требует подтверждения браузера.

Для группы нажмите «Скачать несколько» в Telegram либо «Выбрать файлы в Telegram» в popup/менеджере. Если открыто несколько подключённых вкладок, выберите нужную. Панель показывает **только обнаруженные на текущей странице вложения, до 200**, а не весь канал. После ручной прокрутки нажмите «Обновить список»; ранее показанные вложения могут исчезнуть из списка. Кнопка выбора альбома относится только к его перечисленным элементам.

Отметьте файлы и нажмите «Выбрать папку и скачать». Фильтр типа в этой панели сохраняет уже сделанный выбор, в том числе скрытых фильтром файлов; проверяйте итоговый счётчик. По умолчанию совпавшие имена получают суффикс `(1)`, `(2)` и т. д. Можно выбрать пропуск существующих файлов или **явно включить перезапись**. Перезапись не вызывает отдельного подтверждения для каждого файла. Шаблоны имён: исходное имя, ID сообщения + имя, порядковый номер + имя; небезопасные символы очищаются.

Файлы сохраняются последовательно, один активный файл на очередь. Кнопка «Менеджер загрузок» в popup открывает отдельную вкладку: поиск по имени, фильтры типа/статуса/группы, страницы по 25/50/100 записей. Можно выбрать до 200 записей на разных страницах; **изменение фильтра снимает выбор**. Массовая отмена действует на ожидающие и скачиваемые файлы, повтор — на неудавшиеся, отменённые и прерванные.

Повтор требует нового действия в Telegram и выбора места сохранения. Для доступной группы откроется панель выбора файлов, где нужно заново выбрать папку. Если исходная вкладка уже закрыта или перезагружена, индивидуальная кнопка повтора открывает исходное сообщение, когда ссылка доступна. Массовый повтор сообщает число принятых и отклонённых запросов; для недоступных записей используйте «Открыть исходное сообщение» и выберите вложения заново. Принятый запрос повтора ещё не означает скачанный файл.

Нажмите кнопку активной загрузки ещё раз или «Отменить» в popup/менеджере, чтобы остановить её. Статус «Пропущено» означает совпавшее имя при выбранной политике пропуска, а не новый сохранённый файл.

На коротком завершающем этапе «Записывается на диск» отмена уже недоступна: браузер подтверждает сохранение файла.

Закрытие popup, менеджера или панели выбора не мешает уже добавленной очереди. **Telegram-вкладка должна оставаться открытой.** Её закрытие или перезагрузка прерывает зависимые загрузки. История сохраняется, но побайтовая докачка после перезапуска пока не реализована. Выберите файл заново, чтобы повторить загрузку.

Файлы сохраняются в реальном формате: voice может быть OGG, а «GIF» — MP4. Расширение не перекодирует содержимое. Если расширение медиафайла в имени противоречит фактическому формату, добавляется верное (`clip.gif` → `clip.gif.mp4`); имена документов не меняются. Для фотографий сохраняется лучший доступный в Telegram вариант, который может отличаться от файла до сжатия Telegram.

## Ограничения

- Требуется доступ текущего пользователя к сообщению. Расширение не открывает недоступные каналы и неоплаченные вложения.
- Выбор группы не обходит всю историю чата автоматически и не гарантирует наличие всех элементов альбома в списке.
- Одноразовые и самоуничтожающиеся вложения пока не поддерживаются.
- Исполнитель ограничен 4 GiB на файл; текущий **проверенный в Telegram** размер смотрите в матрице. Потоковый synthetic-тест не доказывает возможность скачать такой размер из Telegram.
- Для Web A фото ограничены 32 MiB; документы сохраняются порциями. Это разные пути загрузки.
- Изменения Telegram могут потребовать обновления адаптера. При неоднозначном источнике расширение откажется от загрузки вместо сохранения другого файла.
- В просмотрщике кнопка доступна только при доказанной связи с сообщением. Если её нет, используйте кнопку в исходном сообщении.
- Firefox, Safari, мобильные браузеры и Windows пока не входят в проверенную поддержку.

## Разработка и проверки

```sh
npm run dev
npm run typecheck
npm run lint
npm test
npm run build
npm run test:e2e
```

E2E использует отдельный тестовый Chromium и синтетические страницы; пользовательский профиль и Telegram-сессия в CI не используются. Для установки тестового браузера: `npx playwright install chromium`.

Для живой проверки `node scripts/qa-samples.ts` создаёт синтетические образцы с SHA-256, сверяет скачанные файлы и замеряет память процессов браузера. Порядок описан в [плане ручной проверки](docs/manual-testing.md).

См. [архитектуру Web A](docs/architecture/web-a.md), [Web K](docs/architecture/web-k.md), [передачу и сохранение](docs/architecture/transport.md) и [план ручной проверки](docs/manual-testing.md).

## Данные и поддержка

Разрешения: локальное хранилище расширения и доступ только к `web.telegram.org`. File System Access запрашивает доступ к выбранному файлу или папке. Расширение не сохраняет дескрипторы доступа и пути папок в истории или настройках. Нет аналитики, сервера загрузок и копирования ключей авторизации. Подробнее: [Privacy](PRIVACY.md).

История хранится локально: до 500 завершённых записей, до 30 дней. Её отключение удаляет завершённые записи; скачанные файлы не удаляются. Сводки групп считаются по сохранившимся записям и меняются после очистки или отключения истории. Popup показывает максимум пять активных и пять последних записей; полный доступ к сохранённой истории — в менеджере.

Ошибки можно сообщить через [GitHub Issues](https://github.com/alex100cent/telegram-all-downloader/issues), не прикладывая приватные ссылки, переписки и коды входа. Укажите сборку из popup (Настройки → «О сборке»; то же значение видно в версии на странице расширений). У неудачной загрузки popup показывает код ошибки и кнопку «Диагностика»: копируется только показанный текст без имён файлов, ссылок и идентификаторов.

Донаты необязательны. Ссылка задаётся владельцем в `src/config.ts`; пока она не задана, кнопка скрыта.
